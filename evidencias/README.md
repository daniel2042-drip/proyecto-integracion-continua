# Evidencias auténticas pendientes de ejecución

Este directorio se llena con la salida REAL de los comandos al ejecutar `bash scripts/capturar_evidencias.sh` en un equipo con Docker.

La actividad no se debe presentar con capturas generadas o inventadas como si fueran resultados reales. Después de ejecutar el proyecto, añade capturas propias de:
1. Construcción de imágenes.
2. Arranque simultáneo.
3. Estado `Up`/`healthy` de ambos contenedores.
4. Red compartida.
5. Pruebas POST y GET.
6. Ejecución exitosa real en GitHub Actions.

Los archivos `*.txt` de evidencia son locales y no se incluyen en Git.
